# The GO flight computer
### What is this?
This repository contains the most if not all files for what is in and on the flight computer. 
### Why?
Trying to improve on working on the hardware design of embedded systems, and also learning Rust at the same time!
### About the board:
Hardware:
* MCU: ATSAMD21G18A-AU
* IMU: BMI323
* Barometer: BMP390
* Flash: W25Q16JVSSIQ
* Radio: Wio-SX1262
* Buzzer
* RGB Led
* 3 Servo Ports
* 2 Pyro Channels
* USB-C
* Micro-SD card reader

Runs off of the [Microsoft UF2-SAMDx1](https://github.com/microsoft/uf2-samdx1) UF2 flashing bootloader
